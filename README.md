# 蓝牙串口助手 (Bluetooth Serial Assistant)

一款安卓上位机 App，支持 **经典蓝牙（SPP/RFCOMM，如 HC-05/HC-06）** 与 **BLE（低功耗蓝牙）** 两种连接方式，
以字符串/HEX 形式收发命令，并支持 **用户自定义命令格式**，一键发送。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 四宫格首页 | 启动即见四个入口：**连接状态 / 蓝牙连接 / 命令管理中心 / 设置中心** |
| 连接状态 | 独立页面：大号状态显示（指示灯 + 设备名 + 模式 + 地址），可**断开连接**或**进入终端** |
| 蓝牙连接 | 点卡片进入设备选择页：经典蓝牙 / BLE 模式切换，设备列表按「已配对设备 / 附近设备」分组，支持搜索与配对 |
| 经典蓝牙 | SPP 连接 HC-06/HC-05 等模块（连接前自动取消搜索、失败自动重试） |
| BLE | 低延迟扫描（显示 RSSI）、自动挑选 TX/RX 特征、可手动配置（按设备记忆）、MTU 协商 |
| 收发日志 | 时间戳 + RX/TX 着色，ASCII / HEX 切换、清空、自动滚屏 |
| 发送格式 | 文本 / HEX 输入，可追加换行（无 / `\r` / `\n` / `\r\n`） |
| 命令管理中心 | 两种命令类型：**静态命令**（名称 + 内容 + ASCII/HEX 编码）+ **滑杆命令**（多个滑杆，各自可设上下限/默认值，配合前缀/后缀/分隔符/数值格式组合发送，用于控制多自由度机械臂等）；均支持追加换行，保存后以快捷按钮显示在终端一键发送 |
| 持续发送 | 终端菜单一键开启：**静态命令**按设定间隔（100ms~2s）循环重复发送（再点一次停止，按钮高亮）；**滑杆命令**开启"拖动即发送"后，每动一次滑杆立即发送一次组合命令，实现连续调参控制 |
| 屏幕常亮 | 设置中心可开关，调试/调参时终端保持屏幕不熄灭 |
| BLE 长命令分包 | 超过 MTU 的数据自动按（MTU-3）字节分包、间隔 30ms 串行发送，长命令不再失败 |
| 连接历史 | 自动记住最近成功连接的设备（模式+地址），连接状态页可**一键重连** |
| 命令导入/导出 | 命令库导出为 JSON 文件（备份/换机迁移），或从文件导入恢复（覆盖式，有确认） |
| 滑杆增强 | 数值可**手动输入**（SeekBar 双向同步）、**复位默认值**、**循环扫描**模式（自动从下限扫到上限再返回并持续发送，舵机/机械臂整机测试） |
| 日志保存 | 终端菜单「保存日志」：将收发记录导出为文本文件（系统文件选择器） |
| 设置中心 | **外观**：主题模式（跟随系统/浅色/深色）、主题颜色（蓝/绿/紫/橙）；**蓝牙**：默认发送换行、日志默认 HEX、连接成功自动进入终端 |
| 界面 | Material 3 风格，支持深色模式 |

## 环境要求

- Android Studio（推荐 2025.2 及以上，本项目使用 AGP 9.3.0 + 内置 Kotlin）
- JDK 17+
- Android SDK Platform 37（`compileSdk 37`）、Build-Tools 36.0.0
- Gradle 9.7.1（由 wrapper 自动下载）

## 构建 APK

> 📦 **直接下载安装**：[GitHub Releases v1.1](https://github.com/FZZZZZZZZZ19/Bluetooth-host-computer/releases/tag/v1.1)（`BluetoothSerialAssistant-v1.1-debug.apk`，Debug 签名，手机下载后直接安装）

### 方式一：Android Studio（推荐）

1. `File → Open` 选择项目根目录 `BluetoothSerialAssistant`
2. 等待 Gradle Sync 完成（首次会联网下载依赖）
3. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`
4. 产物位置：`app/build/outputs/apk/debug/app-debug.apk`

### 方式二：命令行

```bash
# 确保 JAVA_HOME 指向 JDK 17+，且 local.properties 中 sdk.dir 正确
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
```

Debug 版 APK 已用调试证书签名，可直接安装到手机：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 发布 Release 版（需签名）

```bash
# 1. 生成签名密钥（仅首次）
keytool -genkey -v -keystore release.jks -alias key0 \
        -keyalg RSA -keysize 2048 -validity 10000

# 2. 在 app/build.gradle.kts 中配置 signingConfigs，或使用
#    Build → Generate Signed Bundle / APK 向导
# 3. 构建
./gradlew assembleRelease
```

## 使用说明

### 首页（四个入口）

| 入口 | 功能 |
| --- | --- |
| 连接状态 | 查看当前连接详情（设备名/模式/地址/状态灯），断开连接或进入终端 |
| 蓝牙连接 | 选择连接模式（经典蓝牙 / BLE），点进去才显示附近的蓝牙设备列表 |
| 命令管理中心 | 自定义命令格式（文本 / HEX + 追加换行） |
| 设置中心 | 外观背景（主题模式、主题颜色）与蓝牙相关配置（默认换行、HEX 日志、自动进终端） |

### 连接 HC-06 / HC-05（经典蓝牙）

1. 给模块上电，手机系统设置中搜索并配对（HC-06 配对码通常为 `1234`）
2. 打开 App，默认「经典蓝牙」模式，点击右下角扫描按钮
3. 设备列表点击已配对模块 → 自动进入终端界面
4. 输入文本或 HEX 命令，选择换行方式后点击「发送」
   - 注意：HC-06 仅作从机，手机连接后模块 TX/RX 直接接单片机串口；
     波特率由模块固件决定（常见 9600），App 不参与波特率设置

### 连接 BLE 透传模块（如 HM-10、CC2541、nRF52832）

1. 切换到「BLE」模式，点击扫描
2. 点击目标设备连接：App 自动发现服务并选择**第一个可写特征**为发送(TX)、
   **第一个通知特征**为接收(RX)
3. 若自动选择不正确：终端右上角菜单 → **BLE 设置** → 手动选择 TX / RX 特征
   （选择会按设备 MAC 记忆，下次自动应用）
   - HM-10 常用：服务 `0000FFE0-...`，特征 `0000FFE1-...`（可写 + 通知，TX/RX 同一特征）

### 自定义命令格式

1. 终端右上角菜单 → **命令管理中心**（或首页入口）
2. 右下角 `+` 新增命令，选择类型：
   - **静态命令**：名称 + 内容 + 编码格式（ASCII 文本 / HEX 十六进制）+ 追加换行
   - **滑杆命令**（推荐用于机械臂等多自由度控制）：
     - 前缀文本（可选，如 `MOVE `）与后缀文本（可选）
     - **数值分隔符自由输入**：留空 = 无分隔；也可输入空格、逗号、冒号、竖线等任意内容
     - 数值格式（十进制 / 十六进制）
     - 添加任意多个**滑杆**，每个滑杆设置：名称（如"关节1"）、下限、上限、默认值
     - 发送格式示例：前缀 `MOVE ` + 分隔符 `,` + 滑杆[0..180]×2 → `MOVE 90,45`；分隔符改为空格 → `MOVE 90 45`
3. 保存后命令以快捷按钮显示在终端；点击**滑杆命令**会弹出滑杆控制面板：
   拖动各滑杆实时调整数值（自动约束在上下限内），底部实时预览组合命令，点「发送」即可下发

### 持续发送模式

- **开关**：终端右上角菜单 → **持续发送**（勾选开启，也可在设置中心配置默认开关与间隔）
- **静态命令**：开启持续发送后点击命令按钮 → 按间隔（100/200/500/1000/2000ms，设置中心可选）循环重复发送，按钮高亮表示发送中；**再次点击同一按钮停止**
- **滑杆命令**：滑杆面板内开启「拖动即发送」→ 每拖动一次滑杆立即发送一次组合命令，实现连续控制（如机械臂实时跟随滑块角度）
- 断开连接、离开终端页或关闭开关时自动停止持续发送

## 常见问题

- **连接时报 "read failed, socket might closed or timeout, read ret: -1"**：这是模块在 SPP 连接握手时被断开。
  按顺序排查：
  1. 确认模块已上电、LED 处于**待连接状态**（HC-06 连接成功后 LED 常亮，闪烁表示等待连接）
  2. 确认模块**未被其他手机/设备占用**（HC-06 只允许一个主机连接）
  3. **取消配对后重新配对**（手机设置 → 蓝牙 → 删除该设备 → 重新搜索配对，PIN 通常为 1234）——配对信息损坏是此报错最常见原因
  4. 部分手机需要在连接前先关闭蓝牙搜索（本 App 已在连接前自动取消搜索并自动重试一次）
- **Android 12+ 无法扫描/连接**：需要在系统弹窗中授予「附近的设备」权限；
  若被拒绝，请到系统设置中手动开启
- **BLE 扫描不到设备**：确认设备已开启广播；部分手机还需打开「定位」开关
- **提示"未找到可写特征"**：使用终端菜单 → BLE 设置 手动选择 TX/RX 特征
- **长命令发送失败**：BLE 单次写入受 MTU 限制（默认 20 字节，App 已尝试协商到 517）。
  若设备不支持大 MTU，请分段发送
- **HC-06 无响应**：检查模块波特率与下位机是否匹配；确认发送内容是否需带 `\r\n`
- **经典蓝牙连接失败**：先解除配对后重新配对；确保模块已上电且在连接范围内
